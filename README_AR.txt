رفيق الأستاذ — النسخة الأولية
================================
ماذا تحتوي؟
- إعداد مذكرة يومية قابلة للطباعة والحفظ في أرشيف محلي.
- إنشاء خطاطة ذهنية نصية.
- استعمال الزمن وإضافة الحصص.
- تتبع التقويم والدعم.
- اقتراح نشاط تربوي سريع.
- تصدير واستيراد نسخة احتياطية بصيغة JSON.

مهم:
1) هذه نسخة أولية وليست نسخة كاملة من AB DOCS.
2) البيانات تُحفظ داخل المتصفح على نفس الهاتف. لا تمسح بيانات المتصفح قبل تصدير نسخة احتياطية.
3) لا توجد حالياً حسابات مستخدمين أو مزامنة سحابية أو توليد PDF مباشر؛ يمكن استعمال طباعة المتصفح واختيار "حفظ كـ PDF".
4) للحصول على APK، يلزم رفع المشروع إلى استضافة HTTPS مجانية ثم تغليفه باستخدام أداة Android مناسبة، أو استيراده في مشروع Android Studio/App Inventor. هذا المجلد وحده ليس ملف APK.
5) حقوق واسم وتصميم AB DOCS ليست منسوخة؛ هذا مشروع مستقل مستوحى من الفكرة العامة لأدوات الأستاذ.

للتجربة:
افتح index.html في متصفح حديث. ولتثبيت PWA بشكل صحيح، ارفع الملفات إلى استضافة HTTPS (مثل GitHub Pages) وافتح الرابط من Chrome.
